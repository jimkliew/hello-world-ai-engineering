# hello-world-ai-engineering

## Purpose
This repository is for Assignment 1 of the AI Engineering course. It contains personalized "Hello World" scripts in two languages, plus an auto-grader for evaluating classmates' submissions against the assignment criteria.

## Files
- `hello.py` — Python "Hello World" script
- `hello.js` — JavaScript "Hello World" script
- `grade_assignment.py` — Loops a list of GitHub usernames and grades each submission on a 100-point rubric (repo, Python file, JS file, README, personal flare)
- `GRADING.md` — Usage instructions and rubric for the auto-grader

## Personal Flare
Both scripts greet the world from Professor Jim Liew, sharing my Oklahoma roots, my excitement about how AI engineering can support secure public-sector modernization, and my love for chicken fried steaks from J-Pats (highly recommended for your bucket list).

## Running the Scripts
```bash
python hello.py      # Python
node hello.js        # JavaScript
```

## Running the Grader
```bash
python grade_assignment.py jimkliew                 # one or more usernames
python grade_assignment.py jimkliew classmate-one   # multiple usernames
python grade_assignment.py students.txt             # a file of usernames
```
See `GRADING.md` for full details.
